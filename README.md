# Privacy Policy — Reaper Dian [the Slayer]

Last updated: August 2026

Who we are

Reaper Dian [the Slayer] is a Discord bot operated for a single Discord server. This policy covers what the bot collects, why, and how long it's kept.

What we collect

Verification records — when a member posts a screenshot in the verification channel: their Discord user ID, username, the message ID, and a link to the submitted image (hosted on Discord's own CDN). Used to route the request to a moderator for manual approval.
Moderator stats — a Discord user ID, username, and a running count of approvals/rejections for each staff member who reviews verification requests.
Titans leaderboard entries — a Discord user ID and a self-reported in-game clear count, for members who choose to submit to the optional leaderboard.

We do not read or store message text. We do not collect data through bulk member lists or real-time join/leave tracking — every record above is created only when that specific user takes an action (submits a screenshot, runs a command) or a moderator acts on their case.

Where it's stored

In a local data file on the bot's own server — not shared with, sold to, or processed by any third party.

How long we keep it

Verification and moderator-stat records are kept indefinitely for now; we don't yet have an automated deletion schedule for resolved requests. Leaderboard entries are kept as long as the leaderboard feature is active.

Your choices

To remove your data, contact a server moderator or the bot's developer directly and ask for it to be deleted.

Contact

Reach the developer through the Discord server this bot operates in.
